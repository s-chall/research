# Research

Software and research artifacts from my work across education and interdisciplinary research labs.

## Selected engineering projects

### [Bloom's Taxonomy Question Generation](https://github.com/s-chall/mcq-generation-blooms-taxonomy)
**Choa Lab · TypeScript, Python, React, PostgreSQL, Docker**

A question-generation and review platform connecting a TypeScript API, Python workers, and a React researcher portal.

- **Engineering:** transactional outbox, idempotent requests, worker leases, and recovery from duplicate delivery and interrupted processing.
- **Evidence:** [architecture](https://github.com/s-chall/mcq-generation-blooms-taxonomy/blob/main/docs/architecture.md) and [implementation evidence ledger](https://github.com/s-chall/mcq-generation-blooms-taxonomy/blob/main/docs/resume-evidence.md).
- **Current boundary:** deterministic generation provider; AWS infrastructure is defined, but live deployment is unverified.

### [Reading Error Engine](https://github.com/s-chall/reading-error-engine)
**First Grade Literacy Lab · React, TypeScript, FastAPI, PostgreSQL**

An oral-reading review platform that connects word-level predictions with audio evidence and researcher corrections.

- **Engineering:** sequence alignment, background assessment processing, retry, reviewed-data export, and cross-version evaluation.
- **Explore:** [workflow, architecture, and local setup](https://github.com/s-chall/reading-error-engine#readme).
